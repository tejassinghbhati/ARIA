§ 1  ·  System Pipeline

From language to physical action

Four tightly integrated stages translate a free-form natural language command into continuous joint commands. Each stage operates at its own frequency and communicates through well-defined interfaces, allowing independent development and testing.

Stage Component Description Rate Implementation
01
Semantic Planning
 Phi-3-mini decomposes natural language commands into structured SubGoal sequences via zero-shot prompting. Rule-based regex fallback guarantees operation without GPU. SentenceTransformer grounds each object description to scene graph node IDs. on demand Phi-3-mini SentenceTransformers
02
Multimodal Perception
 Synchronised RGB-D, LiDAR, and IMU streams fused via back-projection and optional ICP registration into coloured metric point clouds. IMU pose integrated by dead-reckoning. Occupancy map maintained as a log-odds probabilistic 3D voxel grid. 10 Hz Open3D PointNet++
03
Scene Graph
 A live semantic directed graph of detected objects annotated with 3D centroids, bounding boxes, and CLIP visual embeddings. Spatial predicate edges (on, near, inside, above, below, left_of, right_of) are inferred geometrically and verified via zero-shot CLIP scoring. 10 Hz NetworkX CLIP ViT-B/32
04
RL Policy Execution
 A dense Graph Attention Network processes the scene graph tensor into a 512-dimensional embedding that conditions both policies. PPO outputs continuous [vx, vy, ω] base velocity; SAC outputs 7-DOF joint targets for the Franka arm. 20 Hz SB3 PPO SB3 SAC PyG GAT

Policy architecture and training

Both policies share a common GNN-based feature extractor. The navigation and manipulation environments are implemented in PyBullet with full domain randomisation for sim-to-real transfer.

Navigation Policy · PPO
Mobile base velocity control

  • Parallel environments 8 (SubprocVecEnv)
  • Simulation frequency 240 Hz (PyBullet)
  • Control frequency 20 Hz
  • Action space [vx, vy, ω] ∈ ℝ³
  • Episode length 500 steps
  • Goal threshold 0.3 m radius
  • Learning rate 3 × 10⁻⁴
  • GAE lambda 0.95
  • Clip range 0.2
Manipulation Policy · SAC
Franka Panda joint control
  • Training timesteps 1 500 000
  • Parallel environments 4
  • Action space 7-DOF joint targets
  • Episode length 300 steps

  • Learning rate 3 × 10⁻⁴

  • F/T sensor 6-axis feedback
  • Domain randomisation enabled
  • ONNX export FP32 / TensorRT FP16

Semantic 3D representation
  • Max nodes 64 per scene

  • Predicate types on, near, inside, above, below, left_of, right_of

§ 3  ·  Usage

Minimal working example

The perception and grounding pipeline can be used independently from the RL training stack. The NLPGrounder falls back to a lightweight regex parser when the LLM is unavailable.

quick_start.py python 
from aria.perception.scene_graph import SceneGraph, SceneNode
from aria.perception.nlp_grounding import NLPGrounder
import numpy as np

# Build a scene graph from detection results
sg = SceneGraph(max_nodes=64, use_clip=True)
sg.add_or_update_node(SceneNode(
    node_id=0, class_label="red_mug",
    centroid=np.array([1.2, 0.5, 0.8]),
    bbox_3d=np.array([1.1, 0.4, 0.7, 1.3, 0.6, 0.9]),
    embedding=np.random.randn(512).astype(np.float32),
    confidence=0.94,
))

# Ground a natural language command to the scene graph
grounder = NLPGrounder(cfg={"use_llm": True})
plan = grounder.plan("fetch the red mug from the shelf", sg)

for step in plan:
    print(f"{step.action:<14} '{step.object_desc}'  node_id={step.node_id}")

# navigate_to   'shelf'       node_id=1
# pick_up       'red mug'     node_id=0
# navigate_to   'table'       node_id=2
# place_on      'table'       node_id=2

§ 5  ·  Deployment

Getting started

Requires Python 3.11 and Microsoft Visual C++ Build Tools on Windows for PyBullet compilation. Use the full requirements file for training; the dashboard requirements for the web interface.

Local Installation
# Python 3.11 virtual environment py -3.11 -m venv .venv .venv\Scripts\activate
# Full training stack pip install --timeout 300 -r requirements_full.txt pip install -e .
# Run unit tests python -m pytest tests/unit/ -v
Training & Export
# Navigation policy (PPO) python -m aria.rl.train_nav \ --config configs/nav_training.yaml
# Export to ONNX python -m aria.production.export_onnx \ --nav-model checkpoints/nav/best_model.zip \ --output-dir exports/onnx/
# Monitoring stack cd docker && docker compose up -d
Grafana dashboard at localhost:3000 · Prometheus at localhost:9090
