System Pipeline

From language to physical action

Four tightly integrated stages translate a natural language command into continuous robot control at real-time frequency.

01
🗣️
Semantic Planning
Phi-3-mini LLM decomposes natural language instructions into structured sub-goal sequences via zero-shot prompting.
Phi-3-mini · HuggingFace
02
📡
Multimodal Perception
RGB-D, LiDAR, and IMU streams fused at 10 Hz into dense point clouds. PointNet++ extracts hierarchical geometric features.
Open3D · PointNet++
03
🕸️
Scene Graph
A live semantic graph of detected objects with spatial predicate edges — on, near, above, inside — grounded via CLIP embeddings.
NetworkX · CLIP ViT-B/32
04
🤖
RL Control
Graph Attention Network conditions PPO navigation and SAC manipulation policies to generate continuous joint commands at 20 Hz.
PPO · SAC · GNN
Capabilities

Built for production deployment

Every component is designed to run on physical hardware with real-time constraints.

🔭
3D Multimodal Fusion
Synchronised RGB-D, LiDAR, and IMU fusion with ICP registration, outlier removal, and voxel downsampling into metric point clouds.
🧠
LLM Task Planning
Zero-shot decomposition of free-form commands into grounded sub-goal sequences. Rule-based fallback ensures reliability without GPU.
⚡
ONNX / TensorRT Export
Trained policies export to optimised ONNX with numerical validation, then to TensorRT FP16 for sub-5ms inference on the robot.
🔀
Sim-to-Real Transfer
Per-episode randomisation of textures, lighting, friction, mass, and camera parameters trains policies robust to real-world variation.
🌐
ROS2 Lifecycle Nodes
Perception, language, and policy nodes implement the ROS2 managed lifecycle for clean startup, shutdown, and error recovery on the Franka robot.
📊
Prometheus Observability
Inference latency, policy success rates, scene graph size, and resource utilisation exported in real time to Grafana dashboards.
Architecture

How it all fits together

🗣️
Natural Language Input
"Fetch the red mug from the shelf"
🧩
LLM Planner → SubGoals
navigate_to shelf · pick_up red_mug · navigate_to table · place_on table
📡
Perception Pipeline
Sensor fusion → occupancy map → scene graph construction
10 Hz
🕸️
GNN Feature Extraction
Graph Attention Network over scene graph → 512-dim policy embedding
🤖
RL Policy Execution
PPO → /cmd_vel · SAC → /franka/joint_commands
20 Hz
Navigation Policy (PPO)
  • 2M training timesteps, 8 parallel envs
  • PyBullet physics at 240 Hz
  • Continuous [vx, vy, ω] velocity commands
  • Goal detection within 0.3m radius
Manipulation Policy (SAC)
  • 1.5M timesteps, 500K replay buffer
  • Franka Panda 7-DOF joint control
  • Force-torque sensor feedback
  • Domain randomisation enabled
Scene Graph
  • Up to 64 object nodes per scene
  • 7 spatial predicate types
  • CLIP ViT-B/32 semantic verification
  • Exports dense tensors for GNN input
quick_start.py
from aria.perception import SceneGraph, NLPGrounder sg = SceneGraph() grounder = NLPGrounder() plan = grounder.plan( "fetch the red mug from the shelf", scene_graph=sg ) for step in plan: print(step.action, "→", step.object_desc)
